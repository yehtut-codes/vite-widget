🚀 Widget Embed Examples

This widget works on ANY website including localhost, production sites, and even local HTML files!

✅ Universal Compatibility: This widget can be embedded anywhere using a simple iframe. No special configuration or CORS setup needed!

1. Basic Widget Embed

The simplest way to embed your widget:

<iframe
    src="https://symphonious-faloodeh-a943e6.netlify.app"
    width="400"
    height="300"
    frameborder="0">
</iframe>

2. Widget with Dark Theme

Add URL parameters to customize the widget:

<iframe
    src="https://symphonious-faloodeh-a943e6.netlify.app?theme=dark"
    width="400"
    height="300"
    frameborder="0">
</iframe>

3. Widget with Debug Mode (Open Console)

Add ?debug=true to see debug logs in the browser console:

<iframe
    src="https://symphonious-faloodeh-a943e6.netlify.app?debug=true"
    width="400"
    height="300"
    frameborder="0">
</iframe>

📚 Usage Information

Available URL Parameters:

  • theme - Widget theme (default, dark, premium)
  • debug - Enable debug logging (true/false)
  • apiKey - Your API key (optional)

✅ Works On:

  • ✓ Any production website (HTTPS)
  • ✓ Localhost development servers
  • ✓ Local HTML files (file://)
  • ✓ WordPress, Shopify, Wix, Squarespace, etc.
  • ✓ React, Vue, Angular applications
  • ✓ Static HTML websites
💡 Tip: The widget is hosted on Netlify's global CDN, so it loads fast from anywhere in the world!

⚛️ React Integration Example

}

export default MyComponent;
