Minimal Div+Script Widget Example

How to Use:

  1. Add <link rel="stylesheet" href="dist/assets/my-widget.css"> in your <head>
  2. Add <div id="my-widget-container"></div> where you want the widget
  3. Add <script src="dist/my-widget.iife.js"></script> before </body>
  4. Call window.initMyWidget() to initialize
