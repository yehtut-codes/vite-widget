🚀 Div+Script Embeddable Widget

A simple, JavaScript-based widget that can be embedded on any website

📚 What is a Div+Script Widget?

A div+script widget is the most common way to embed third-party functionality on websites. It consists of two parts:

  1. A <div> container - Where the widget will be rendered
  2. A <script> tag - That loads and initializes the widget

This approach is used by Google Analytics, Disqus Comments, Facebook widgets, and many other popular services.

⚡ How to Implement (3 Simple Steps)

1

Add the CSS link

Include the widget stylesheet in your HTML <head> section

<link rel="stylesheet" href="path/to/my-widget.css">
2

Add the container div

Place this where you want the widget to appear

<div id="my-widget-container"></div>
3

Load and initialize the widget

Add these script tags at the end of your <body>

<script src="path/to/my-widget.iife.js"></script> <script> window.initMyWidget(); </script>
✨ That's it! The widget will automatically render in the container.

💻 Complete Example Code

Copy and paste this into any HTML file to embed the widget:

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>My Website with Widget</title> <!-- Widget CSS --> <link rel="stylesheet" href="dist/assets/my-widget.css"> </head> <body> <h1>Welcome to My Website</h1> <!-- Widget Container --> <div id="my-widget-container"></div> <!-- Widget JavaScript --> <script src="dist/my-widget.iife.js"></script> <script> // Initialize the widget window.initMyWidget(); </script> </body> </html>

⚙️ Configuration Options

You can customize the widget by passing configuration options:

window.initMyWidget({ theme: 'dark', // Options: 'light', 'dark', 'default', 'premium' apiKey: 'your-api-key' // Optional API key });

Available Options:

theme

Visual theme for the widget. Options: 'light', 'dark', 'default', 'premium'

apiKey

Your API key for authenticated features (optional)

locale

Language/locale code like 'en-US', 'es-ES' (optional)

🤔 Why Use Div+Script Embedding?

✅ Pros

• Simple implementation
• Works on any website
• No iframe overhead
• Direct DOM access
• Easy to customize

⚠️ Cons

• Requires hosting files
• Larger initial load
• Potential CSS conflicts
• Global namespace usage

🎯 Best For

• Internal tools
• Trusted partners
• Custom integrations
• Full-featured widgets
